( The project )

Packing Pigeon prints custom stand-up pouches for food, coffee and wellness brands across Canada and the US, with low minimums and fast turnaround. Buyers need to configure a product, see the price, upload artwork and pay, all without a sales call.

The store is headless. WooCommerce runs the catalog, cart, orders and payments behind a custom WordPress REST API, and a React storefront handles everything the customer sees. I worked on both sides: the API controllers and models, and the React app's pages, cart, product forms and mobile layouts.

What I built.

  • 01

    A custom WooCommerce API

    REST endpoints for products, templates, categories, cart, checkout, accounts, reviews, blog and newsletter, so the React app never touches WordPress pages.

  • 02

    Configure and price

    Product forms for size, material, finish and quantity with instant pricing, plus sample orders and a request-a-quote flow for bigger runs.

  • 03

    Artwork upload

    Drag-and-drop artwork upload tied to the order, so production gets the files with the purchase instead of over email.

  • 04

    Stripe checkout & accounts

    Stripe payments in the React checkout, customer accounts with email verification codes, and order history.
